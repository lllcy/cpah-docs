CPAH Docs v1.5.2 prevents multiple app instances from processing the same task database and restores the existing window on repeated launches.

CPAH Docs v1.5.2 增加单实例限制，避免多个程序同时处理同一任务数据库；再次启动会显示并恢复已有窗口。

- **Single instance / 单实例运行**: A second launch exits before opening the task database or starting watching, conversion, classification or indexing. The running app's hidden or minimized main window is shown, restored and focused. 第二次启动会在打开任务数据库和启动监听、转换、分类、索引之前退出；已运行程序的主窗口会显示、恢复并获得焦点。
- **Version compatibility guidance / 版本兼容提示**: Unknown conversion-engine errors are identified as task-record compatibility problems, with instructions to quit older versions from the system tray and retry in the latest version. “未知转换引擎”错误会提示任务记录的版本兼容问题，说明从托盘退出旧版后，在最新版中重试。
- **PDF source limit / PDF 源文件上限**: Local PDF conversion and MinerU splitting accept source PDFs up to 1 GiB. OCR PDFs exceeding 200 MB continue to split losslessly before upload. 本地 PDF 转换和 MinerU 拆分均支持不超过 1 GiB 的源文件；需要 OCR 且超过 200 MB 的 PDF 仍在上传前无损拆分。

Before upgrading from v1.5.1 or earlier, quit every old copy from the system tray. Those older executables do not implement the new single-instance restriction. Closing their windows only hides them. 升级前请从托盘退出所有 v1.5.1 及更早的程序；旧版 EXE 本身没有单实例限制，关闭窗口只会隐藏到托盘。

This build also includes v1.5.1's watching-status clarification and recognition of HTML/RTF/Word content in files named `.doc`, `.docx` or `.docm`. 本版包含 v1.5.1 的监听状态提示修正，以及 `.doc/.docx/.docm` 文件按实际 HTML、RTF 或 Word 内容解析的兼容。
