CPAH Docs v1.5.0 adds local conversion of MHTML/MHT web archives and fixes cross-folder interference when a watched folder is moved or becomes unavailable.

CPAH Docs v1.5.0 新增 MHTML/MHT 网页存档本地转换，并修复移动或失效的监控目录影响其他目录扫描的问题。

## What's new / 本次更新

- **Local web archive conversion / 网页存档本地转换**: Convert `.mhtml` and `.mht` archives to Markdown locally, preserving readable page content, links and embedded images. No browser or cloud conversion service is required. 本地转换 `.mhtml`、`.mht` 网页存档，保留可读取的正文、链接和内嵌图片，无需浏览器或云端转换服务。
- **Independent folder scanning / 多目录扫描修复**: A missing, unreadable or otherwise failing folder no longer prevents healthy folders from discovering and queuing files during startup, manual rescans or periodic scans. 启动、手动重新扫描和周期扫描时，一个目录缺失、不可读或扫描失败，不再阻止其他正常目录发现文件并加入任务。
- **Continuous watching when settings change / 目录变更时持续监听**: Updating one folder keeps unchanged folders subscribed. Watch registration and removal failures are isolated and retried on subsequent reloads and periodic checks. 修改一个目录时保留其他目录的监听，避免整体重载造成漏录；监听注册或移除失败会独立记录并在后续重载及周期检查中重试。
- **Regression coverage / 回归验证**: Added eight regression tests covering unavailable inputs and outputs, watch failures, startup discovery, folder changes, and conversion into separate output folders. 新增八条回归测试，覆盖失效输入与输出、监听失败、启动扫描、目录变更和分别输出转换结果。

## Downloads and upgrade / 下载与升级

- **Windows x64**: `CPAH-Docs-v1.5.0-windows-x64.exe`. Run the executable directly; WebView2 Runtime is required. 下载后直接运行，需要 WebView2 Runtime。
- **macOS universal / macOS 通用版**: `CPAH-Docs-v1.5.0-macos-universal.dmg`. Supports Apple Silicon and Intel. 同时支持 Apple Silicon 与 Intel。
- Verify downloads with `SHA256SUMS.txt`. Project and third-party licenses are included. 使用 `SHA256SUMS.txt` 校验下载文件，项目许可和第三方许可一并提供。

Upgrading preserves existing folders, credentials, format selections and queue pause settings. Existing users can enable **Web archives** (`.mhtml`, `.mht`) in the format settings. If a source folder was moved, update its input path in the folder settings; rescan to discover files previously missed in other folders.

升级保留原有目录、凭据、格式选择和队列暂停设置。已有用户可在格式设置中启用“网页存档”（`.mhtml`、`.mht`）。输入目录移动后，请在目录设置中更新输入路径；重新扫描可补录其他目录此前遗漏的文件。

This release does not use commercial or Apple Developer signing certificates, and the macOS build is not notarized.

当前构建未使用商业或 Apple Developer 证书签名，macOS 版本未公证。
