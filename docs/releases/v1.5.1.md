CPAH Docs v1.5.1 clarifies folder watching controls and fixes local conversion of Word exports whose contents do not match their `.doc`, `.docx` or `.docm` extension.

CPAH Docs v1.5.1 明确目录监听的控制范围，并修复扩展名为 `.doc`、`.docx` 或 `.docm` 的网页及其他 Word 导出文件无法本地转换的问题。

- **Clear watching status / 监听状态更清楚**: Global controls now say “Start all watching” and “Pause all watching”. Paused folders show a gray indicator and “Paused globally”, while disabled folders retain their disabled state. The folder settings explain how individual enablement interacts with global pause. 总开关改为“全部开始监听／全部暂停监听”；全部暂停时，目录显示灰色“已暂停（全部）”，停用的目录仍显示“已停用”。目录设置说明单独启用与全部暂停的关系。
- **Word export recognition / Word 导出文件识别**: Files named `.doc`, `.docx` or `.docm` are routed by recognizable HTML, RTF, binary Word or DOCX content. HTML exports preserve headings, tables and links, and support UTF-8, UTF-16 and declared encodings such as GBK. Unrecognized or damaged Word containers still report an error. 扩展名为 `.doc`、`.docx` 或 `.docm` 的文件会按实际的 HTML、RTF、二进制 Word 或 DOCX 内容选择本地解析器；HTML 保留标题、表格和链接，支持 UTF-8、UTF-16 及声明为 GBK 等编码的中文正文。无法识别或损坏的 Word 容器仍正常报错。

Pausing watching stops discovery of new files. Existing conversion tasks remain controlled on the conversion task page. 暂停监听只停止发现新文件；已有转换任务仍在转换任务页独立控制。
