CPAH Docs v1.5.3 reduces memory use when processing large PDFs by splitting them on disk with an embedded QPDF runtime before sequential local extraction.

CPAH Docs v1.5.3 内置 QPDF，大 PDF 先在磁盘上拆分再逐片提取文字，降低整份读入和复制 PDF 导致的内存峰值。

- **Large PDFs / 大 PDF**: Sources larger than 64 MiB use QPDF before local extraction. Local chunks target 32 MiB and at most 50 pages; a single page cannot be subdivided and may exceed that target. 超过 64 MiB 的 PDF 先拆分，本地提取分片目标为 32 MiB、最多 50 页；单页无法再按页拆分，可能超过目标大小。
- **MinerU / MinerU 拆分**: Large OCR PDFs and regenerated retry inputs also use QPDF, preserving the existing 200-page and upload-size constraints. 大 OCR PDF 及重试时重新生成的分片使用 QPDF，保留已有页数和上传大小限制。
- **Portable runtime / 免安装依赖**: Official QPDF 12.4.2 binaries are verified against pinned SHA256 values at build time and compressed into the executable. They are extracted locally when needed. Windows helper processes run without console windows. 构建时校验官方 QPDF 12.4.2 的固定 SHA256；运行文件压缩内置，需要时自动解压，Windows 不弹出命令行窗口。
- **Cancellation and output / 取消和输出**: Directory cancellation stops QPDF processing. Temporary local chunks are cleaned on success, failure and cancellation. Local text is merged in page order; any OCR page triggers the existing OCR route without writing an incomplete result. 删除目录取消任务时会停止 QPDF；成功、失败和取消均清理本地临时分片。按页序合并文字，存在扫描页时仍转入 OCR，不写入不完整结果。
- **Dependency security / 依赖安全**: Updates `rustls` to 0.23.46 and `quinn-proto` to 0.11.18 to address the seven vulnerability advisories reported by the release-time RustSec audit. 将 `rustls` 更新至 0.23.46、`quinn-proto` 更新至 0.11.18，修复发布前 RustSec 检查报告的七条漏洞记录。

The source-PDF cap remains 1 GiB. A single-page chunk of 190 MB or more cannot be subdivided further and is rejected. Memory still depends on PDF object complexity and individual page size. QPDF performs local structural splitting; text extraction and OCR continue to use the existing engines. PDF 源文件上限为 1 GiB；单页分片达到或超过 190 MB 时无法继续按页拆分，会提示失败。实际内存占用仍受对象复杂度和单页大小影响。QPDF 只负责本地拆分，文字提取和 OCR 继续使用现有引擎。

Includes v1.5.2's single-instance restriction and v1.5.1's Word-content compatibility and clearer monitoring controls. Quit all v1.5.1 or earlier copies from the system tray before launching the new build. 包含 v1.5.2 的单实例限制，以及 v1.5.1 的 Word 内容兼容和监听状态提示修正。使用前请从托盘退出所有 v1.5.1 及更早版本。
