CPAH Docs v1.3.0 升级文档转换内核，并加入安全删除监控目录和 JSON 批量导入类别。

## 本次更新

- **anydoc 本地转换**：Office 改用 anydoc 0.2.4，旧版 DOC / PPT 也可本地处理，新增宏启用 Office、OpenDocument、EPUB、RTF 等格式，保留可读取的内嵌图片附件。
- **PDF 按需 OCR**：先在本地提取，仅在解析器明确判定需要 OCR 时，将整份 PDF 交给 MinerU；损坏、加密或超限错误不会触发上传。保留大型 PDF 分片、恢复和重试。
- **保留轻量格式处理**：HTML、HTM、TXT 继续使用 anytomd；Markdown 按字节原样同步。
- **安全删除监控目录**：取消相关转换、分类、索引及分片任务，等待活动写入结束，再清理任务记录和 MinerU 缓存；源文件与已生成文件保留。
- **JSON 批量导入类别**：在目录设置中粘贴 `name` / `description` 数组，支持整批校验、同名说明冲突预览与统一处理；自动保存规则，不启动历史分类任务。
- **取消与并发修复**：防止旧窗口恢复已删除目录、旧文件操作重新入队，以及分类响应或后台解压在删除后继续写入。

## 下载与升级

- Windows x64：`CPAH-Docs-v1.3.0-windows-x64.exe`，下载后直接运行，需要 WebView2 Runtime。
- macOS：`CPAH-Docs-v1.3.0-macos-universal.dmg`，同时支持 Apple Silicon 与 Intel。
- 使用同页的 `SHA256SUMS.txt` 校验下载文件；项目许可和第三方许可一并提供。

升级保留原有目录、凭据和队列暂停设置。普通文本 PDF 与 Office 无需 MinerU Token；图片和需要 OCR 的 PDF 仍需配置 Token。此前已完成的文档不会自动重新转换。

本地 PDF 保留文字、表格和图片占位，不导出 PDF 图片附件。当前构建未使用商业 / Apple Developer 证书签名，macOS 版本未公证。
