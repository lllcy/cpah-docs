CPAH Docs v1.4.0 adds English and Simplified Chinese interfaces, automatic system-language detection and bilingual project documentation.

CPAH Docs v1.4.0 新增英文与简体中文界面、系统语言自动识别，以及双语项目文档。

## What's new / 本次更新

- **Language selection / 语言选择**: The interface follows the system language on first launch. Choose English or Simplified Chinese in Settings; the choice is saved for future launches. 首次启动自动识别系统语言，可在设置中切换英文或简体中文，并记住选择。
- **Localized interface / 完整界面本地化**: Navigation, help, task states, dialogs, accessibility labels, error guidance, dates, numbers, file sorting, native tray menus and managed knowledge-index headings support both languages. 导航、帮助、任务状态、对话框、无障碍标签、错误建议、日期、数字、文件排序、托盘菜单和索引托管标题支持两种语言。
- **Bilingual documentation / 双语项目文档**: English project documentation, retained Chinese versions, bilingual issue/PR templates and a translation contribution guide. 提供英文项目文档与中文版本、双语 Issue/PR 模板，以及翻译贡献指南。
- **Release checks / 发布校验**: Internationalization checks run in CI and the Windows/macOS release scripts. Windows installer configuration supports English and Simplified Chinese. CI 与 Windows/macOS 发布脚本增加国际化检查，Windows 安装器配置支持英文与简体中文。
- **Build dependency security / 构建依赖安全**: Updated source-map-js to 1.2.2 to address [CVE-2026-93749](https://github.com/advisories/GHSA-68fv-2mgg-jv7q). 将 source-map-js 更新至 1.2.2，修复 CVE-2026-93749。

## Downloads and upgrade / 下载与升级

- **Windows x64**: `CPAH-Docs-v1.4.0-windows-x64.exe`. Run the executable directly; WebView2 Runtime is required. 下载后直接运行，需要 WebView2 Runtime。
- **macOS universal / macOS 通用版**: `CPAH-Docs-v1.4.0-macos-universal.dmg`. Supports Apple Silicon and Intel. 同时支持 Apple Silicon 与 Intel。
- Verify downloads with `SHA256SUMS.txt`. Project and third-party licenses are included. 使用 `SHA256SUMS.txt` 校验下载文件，项目许可和第三方许可一并提供。

Upgrading preserves existing folders, credentials and queue pause settings. Switching languages preserves user filenames, paths, folder names, custom categories and document content. The reserved `未分类` YAML value remains unchanged and displays as “Unclassified” in English.

升级保留原有目录、凭据和队列暂停设置。切换语言保留用户文件名、路径、目录名称、自定义类别和正文；YAML 中的保留值 `未分类` 保持不变，英文界面显示为 Unclassified。

This release does not use commercial or Apple Developer signing certificates, and the macOS build is not notarized.

当前构建未使用商业或 Apple Developer 证书签名，macOS 版本未公证。
