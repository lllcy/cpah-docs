CPAH Docs v1.2.0 增加了目录文件树、单文件操作和决策模型分类。

## 本次更新

- **文件树**：查看监控目录中的全部文件与转换状态，支持展开文件夹、搜索、筛选和查看详情。
- **单文件转换 / 分类**：在文件详情底部点击按钮，选中文件优先处理，结束后继续其他同类任务；暂停的对应队列会恢复，已执行的任务不被中断。
- **两种分类模型**：可选大语言模型或 System One 兼容决策模型。决策模式最多提交前 32 KiB Markdown，模型选项提供简短悬停说明。
- **界面改进**：导航可收起、已保存密钥显示密码占位、错误提示可关闭且不会反复弹出。
- **全新图标**：透明背景的紫蓝色文档与文件夹图标。
- **安全修复**：更新 rustls，修复 RUSTSEC-2026-0285。

## 下载

- Windows x64：`CPAH-Docs-v1.2.0-windows-x64.exe`，下载后直接运行，需要 WebView2 Runtime。
- macOS：`CPAH-Docs-v1.2.0-macos-universal.dmg`，同时支持 Apple Silicon 与 Intel。
- 使用同页的 `SHA256SUMS.txt` 校验下载文件；许可文件随版本一同提供。

当前构建未使用商业 / Apple Developer 证书签名，macOS 版本未公证。升级会保留原有目录、凭据和队列暂停设置；点击详情中的转换或分类按钮会恢复对应队列。
